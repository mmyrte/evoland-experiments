# SSP-CH

This is an implementation of the SSP-CH scenarios previously implemented for [the SSP-CH scenario project](https://ssp-ch-szenarien.wsl.ch/en/), which focused on developing a Swiss-specific operationalisation of the SSP scenarios.

Nota bene that SSP2 was left out due to a policy bias to regard it as a business-as-usual scenario, which is against the intention of scenario-based approaches: that a maximally diverse set of possible futures is represented.

See previous results at <https://zenodo.org/records/17108008>.
